# 🚦 Smart Crosswalk Safety System

An AI-powered Intelligent Traffic Monitoring and Pedestrian Safety Platform that leverages **YOLOv8 Object Detection**, **Flask**, and **Computer Vision** to improve road safety by monitoring pedestrian crossings, vehicle movement, and traffic conditions in real time.

---

## 📌 Project Overview

The Smart Crosswalk Safety System is designed to enhance pedestrian safety by detecting pedestrians, vehicles, and crosswalk activities using Artificial Intelligence. The system provides real-time monitoring, analytics, and intelligent alerts through an intuitive web dashboard.

This project demonstrates how AI and Computer Vision can be integrated into smart city infrastructure to reduce accidents and improve traffic management.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/Smart-Crosswalk-Safety-System.git
```

### Navigate to Project

```bash
cd Smart-Crosswalk-Safety-System
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python run.py
```

Open your browser:

```
http://127.0.0.1:5000
```

## 📊 System Workflow

1. User logs into the application.
2. Uploads an image or video, or starts live camera monitoring.
3. YOLOv8 detects pedestrians and vehicles.
4. Detection results are processed.
5. Dashboard displays live analytics.
6. Reports and history are stored.
7. Administrators monitor overall traffic activity.
