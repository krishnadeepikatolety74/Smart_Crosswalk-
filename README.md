# 🚦 Smart Crosswalk Safety System

An AI-powered Smart Crosswalk Safety System that enhances pedestrian safety through real-time object detection, traffic monitoring, and intelligent analytics. The system leverages Computer Vision and Deep Learning to detect pedestrians, vehicles, and crosswalks, helping reduce road accidents and improve urban traffic management.

---

## 📌 Overview

The Smart Crosswalk Safety System is designed to monitor pedestrian crossings using AI-based object detection. It analyzes live camera feeds or uploaded images/videos to detect pedestrians, vehicles, and traffic conditions, providing visual insights through an interactive web dashboard.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/krishnadeepikatolety74/Smart_Crosswalk-.git
```

Navigate to the project

```bash
cd Smart_Crosswalk-
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```
